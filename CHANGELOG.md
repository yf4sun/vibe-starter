# Changelog

All notable changes to this project are listed here, newest first.
Written for users of the tool, not just developers.

## [Unreleased]
### Added
- Volume summary script: shows volumes for each turning movement (NBL to WBR),
  totals for each approach, and the intersection total. Missing counts are shown
  as "n/a" and any total that leaves them out is marked as incomplete.
- Option to save the summary as a CSV file in the `output` folder
  (run with `--csv`).
